Sequences
=========

The sequences module lets an Optic be traced through user-defined sub-sequences: alternative traversal orders over the same surface objects, for ghost paths, reverse traces, and sub-component views. See the :doc:`developer's guide <../developers_guide/sequences_framework>` for the architecture.
